# WDSP provenance and license

WDSP (Warren Pratt NR0V's DSP library) is vendored in
`third_party/wdsp/`.

## Upstream baseline

- **Author:** Warren Pratt (NR0V, W5WJ)
- **Canonical repository:** <https://github.com/TAPR/OpenHPSDR-wdsp>
- **Imported tree:** `wdsp 2.10/Source`
- **Pinned commit:** `b02d5bac675dd2f33ec2bab2b339f79a597c47dd`
- **Import date:** 2026-09-21

The reproducible 170-row pre-import union, SHA-256 values, compile decisions,
and per-file dispositions are recorded in
[`vendor-inventory.md`](../architecture/wdsp210-verification/vendor-inventory.md)
and its adjacent `source-manifest.csv`. The manifest was checked independently
with zero hash mismatches.

The compiled non-Windows library has an explicit list of 83 C translation
units. It contains 77 files from the pinned WDSP 2.10 tree and six retained
Nereus files: `linux_port.c`, `netinterface_stub.c`, `ps_sync_stub.c`,
`rnnr.c`, `sbnr.c`, and `txgain_stub.c`. Windows removes `linux_port.c` from
that explicit list. Upstream's dormant `snoop.c` is excluded, and its
monolithic `wdsp.h` is not used as the application ABI. The obsolete local
`FDnoiseIQ.c/.h` and `fastmath.h` were removed.

Across the 167 current `.c` and `.h` files, 156 names come from the pinned
tree and 11 are retained or new Nereus files. Of the pinned names, 126 remain
byte-identical and 30 contain the reviewed integrations below. These counts
describe source identity, not authorship: modified files retain their upstream
notices and remain derived from WDSP.

copying those algorithms into Nereus wrappers:

| Area | Pinned WDSP 2.10 files | Disposition |

| PureSignal 3 curve fitting | `calcc.c/.h`, `iqc.c/.h`, `extrapolate.c/.h`, `nurbs_fit.c/.h`, `nurbs_spline.c/.h` | Imported from the pinned TAPR commit, then given the bounded status, parser, portability, and teardown changes listed below. |

The model assets remain GPLv2-or-later WDSP source files. Their encoded format,
hashes, tensor counts, decoded sizes, and parser bounds are recorded in the
vendor inventory. No separate model license was invented for this import.

## Reviewed downstream integrations

The following pinned files differ from commit `b02d5bac` for compatibility,
portability, or input/lifetime hardening. The changes do not change their
upstream attribution.

| Category | Files | Nereus disposition |
| --- | --- | --- |
| NR3/NR4 composition | `RXA.c/.h`, `amd.c`, `anf.c`, `anr.c`, `emnr.c`, `snb.c`, `comm.h` | Retain the Thetis-derived RNNR/SBNR modes while composing them with pinned NNR creation, execution, resize/rate changes, destruction, and bandpass arbitration. |
| NNR status and parser boundary | `nnet.c/.h`, `nnio.c`, `nnr.c/.h` | Add accepted source/status readback, null/partial-build cleanup, checked descriptor arithmetic, bounded allocation, and the Nereus compatibility adapter used by Core. |
| CFC compatibility | `TXA.c`, `cfcomp.c/.h` | Preserve Nereus's measured 2048-point construction default and seven-argument `SetTXACFCOMPprofile(F,G,E,Qg,Qe)` ABI. The independent-Q Gaussian-tail compatibility path comes from the prior Thetis v2.10.3.13 integration at commit `501e3f51`; pinned split linear/NURBS setters remain available and clear only their own Q mode. |
| PS3 lifecycle and ABI | `calcc.c/.h`, `iqc.c/.h`, `nurbs_spline.c` | Add durable worker/IQC stop cancellation, confirmed worker exit before frees, active-stream and quiescent correction stop paths, retained-correction availability/reapply, bounded display copies, correction-file operation generations/results, checked 256-byte paths, and bounded v2 correction parsing. |
| POSIX/public-header portability | `extrapolate.c`, `nurbs_fit.c`, `wbfm.c`, `resample.h`, `comm.h` | Supply the audited aligned-allocation declarations, `INT_MAX` include, POSIX helper mappings, and standalone public-header spelling needed by the static macOS/Linux build. |
| Opaque run diagnostics | `cfir.c/.h`, `emph.c/.h` | Add null-safe run readbacks so host diagnostics do not dereference pinned opaque handles. |
| Filter-resize ownership | `emph.c`, `fmd.c` | Retain the replacement filter-curve object returned after freeing the old one. Pinned `b02d5bac` discarded that return value in both coefficient-count setters, causing a use-after-free on live RX/TX filter resize. |

`linux_port.c/.h` remains the existing Warren Pratt NR0V and John Melton
G0ORX/N6LYT POSIX shim, including the preserved DL1YCF comments. Nereus retains
its Linux initial-semaphore-count correction and macOS process-unique,
`O_EXCL`, immediate-unlink semaphore handling. The 2.10 import adds EINTR-safe
single waits, monotonic finite deadlines, fair wait-any behavior, explicit
unsupported wait-all failure, event initial state, and the new WDSP mappings.

The narrow Nereus-authored `ps3_abi.h` publishes only the fixed display
geometry and opaque PS3 status/lifecycle boundary. Its lifecycle calls request
the pinned IQC `END`/`BEGIN` transitions, provide a separately preconditioned
quiescent stop, report retained correction availability, and expose bounded
file-operation cancellation/status; the DSP correction algorithms remain in
the imported WDSP sources. `nnr_compat.h` similarly contains
configuration/status structures and calls into WDSP's NNR implementation; it
contains no copied DSP algorithm.

## Retained Thetis extensions

`rnnr.c/.h` and `sbnr.c/.h` were ported earlier from Thetis v2.10.3.13 commit
`501e3f51`. Their full GPLv2-or-later and Richard Samphire MW0LGE notices are
preserved in the files. RNNR links to the separately tracked Xiph RNNoise
dependency; SBNR links to the separately tracked libspecbleach dependency.

The earlier 2026-04-30 partial `cfcomp.c/.h` sync from that same Thetis commit
is superseded as a baseline by this full TAPR WDSP 2.10 import. Its independent
Qg/Qe behavior remains as a deliberate compatibility layer, with the source
lineage above retained in this record and in the sync log.

authorship/license text as part of the GPLv2-or-later combined
`wdsp_static` source distribution.

## License census

The current tree contains 167 `.c`/`.h` files: 83 C sources and 84 headers.
The header census finds 162 GPLv2-or-later files and five documented
utility headers/sources without a standalone WDSP permission block:

- `fftw3.h` is the upstream FFTW public header; FFTW's provenance is tracked
  separately in `FFTW3-PROVENANCE.md`.
- `resource.h`, `resource1.h`, `version.c`, and `version.h` are pinned WDSP
  resource/version utility files.

The audit normalizes both plain and star-prefixed block comments, so
`nnr_compat.h` is counted by its actual GPLv2-or-later permission text.
The WDSP gate also checks all three registered source-derived Core adapters.

No imported WDSP algorithm file carries GPLv2-only language. The pinned WDSP
sources use GPLv2-or-later. NereusSDR is distributed under GPLv3, so the
upstream "version 2 or any later version" grant permits the combined
distribution under GPLv3.

## Verification record and limits

On Apple Clang/arm64 macOS, the 83-unit static library and the application
compiled after the import. The linked `tst_linux_port_wait`,
`tst_wdsp_ps_smoke`, `tst_tx_channel_ps_setters`, and
`tst_wdsp210_cfc_compat` targets passed. The real linked NNR target passed in
34.78 seconds. The frozen CFC fixture was not regenerated.

These checks establish the macOS software boundary only. Linux and Windows
build/runtime gates, sanitizer lifetime coverage, and hardware/RF acceptance
remain separate verification work; this document does not infer those results.
