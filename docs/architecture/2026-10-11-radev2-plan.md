# Experimental RADE v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add explicitly selectable experimental RADE2-U/RADE2-L modes while preserving RADE V1 and proving real speech through the existing host wrapper.

**Architecture:** Refresh the Python-free vendored codec, preserving native build patches. Configure the codec version before start and reuse the existing per-slice lifecycle and audio routing. Append mode enum values and extend mode-domain consumers.

**Tech Stack:** C++20, Qt6, C RADE, pinned Opus/FARGAN, CMake/Ninja.

**Spec:** docs/architecture/2026-10-11-radev2-experiment.md

## Global Constraints

- V1 remains selectable; no existing enum values are renumbered.
- Explicit experimental RADE2-U/RADE2-L modes; no custom visual theme.
- No radio connections or keying during verification.
- Core/models include no GUI headers; audio callback never waits on a new mutex.
- Keep all existing build portability, archive hash, model-cache patches and upstream notices/comments.
- V2 EOO has no V1 callsign bits; first integration supports speech and EOO, not streaming text reporting.
- Retain current RADE filter window and speech DSP parameters in this experiment.
- Read docs/development/fast-test-loop.md; build/run selected affected tests only.

## Review Focus

- V1/V2 switching while a decode job is pending must tear down safely.
- Remote clients must accept the appended native modes without admitting arbitrary mode integers.
- V2 EOO with zero text bits must not invoke the V1 text decoder or emit stale callsigns.
- Upper/lower variants must map to USB/LSB at both WDSP and radio board boundaries.
- V2 neural convolution workspace must use the new Opus patch on all platform build paths.
